### CRC-31: ReferenciaVisual

* **Tipo:** Value Object (Imutável)
* **Responsabilidades:**
  - Armazenar a chave identificadora do asset gráfico ou elemento visual correspondente a um `ObjetoContado`.
  - Fornecer fábrica estática para instância definida ou não definida (`naoDefinida`).
  - Indicar se existe chave visual configurada para renderização (`estaDefinida`).
* **Colaboradores:**
  - `ObjetoContado`
